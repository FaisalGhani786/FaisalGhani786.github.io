    Pwned Check

    Checks whether a password has appeared in a real data breach, without the password ever leaving your device. The browser hashes it, sends only the first 5 characters of the hash to the Have I Been Pwned database, and finds the match locally. This technique is called k-anonymity.

    What it shows
    • Hashing with the Web Crypto API (SHA-1)
    • Privacy by design with k-anonymity
    • Working with a public REST API
    • Unit tests that prove the password is never sent
    • CI/CD: GitHub Actions tests, then deploys

    Firewall Simulator

    Write firewall rules, fire traffic at a small network and watch every packet get allowed or blocked. Each decision names the rule that made it, and the simulator warns about shadowed rules that can never fire. Scenarios include a port scan and an SSH brute-force attempt.

    What it shows
    • IPv4 and CIDR subnet maths with bitmasks
    • First-match rule evaluation and default-deny policy
    • A small rule language with line-numbered errors
    • Shadowed-rule detection, a real misconfiguration check
    • 10 unit tests, CI/CD with GitHub Actions
